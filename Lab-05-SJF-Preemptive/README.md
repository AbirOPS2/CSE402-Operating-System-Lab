## Experiment
SJF Preemptive (Shortest Remaining Time First - SRTF) CPU Scheduling Algorithm

## Objective
- To implement SJF Preemptive (SRTF) CPU Scheduling Algorithm
- To calculate CT, TAT, WT for each process
- To compare with SJF Non-Preemptive scheduling

## Files
- Source Code
- Lab Report

## Language
Python

## Key Concept
In SRTF, the process with the shortest remaining burst time is executed at every time unit. If a new process arrives with a shorter remaining time than the currently running process, the CPU switches to the new process (preemption).
