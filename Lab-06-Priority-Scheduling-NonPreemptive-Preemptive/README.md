## Key Concept
In Priority Scheduling, each process is assigned a priority number (lower number = higher priority, or vice versa depending on convention). 
- Non-Preemptive: Once a process starts execution, it runs to completion.
- Preemptive: If a higher priority process arrives while a lower priority process is running, the CPU switches immediately.
