# Lab 08

## Experiment
FIFO (First In First Out) Page Replacement Algorithm

## Objective
- To implement the FIFO Page Replacement Algorithm
- To count page hits and page faults
- To calculate the hit ratio and fault ratio

## Given Data
- Reference String: 1, 2, 3, 4, 2, 3, 1
- Frame Size: 3

## Result
| Metric | Value |
|--------|-------|
| Page Hits | 2 |
| Page Faults | 5 |
| Hit Ratio | 28.57% |
| Fault Ratio | 71.43% |
